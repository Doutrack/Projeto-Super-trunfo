Super Trunfo

Projeto desenvolvido em linguagem C com o objetivo de simular uma versão simplificada do jogo Super Trunfo, utilizando conceitos fundamentais de programação, como variáveis, entrada e saída de dados, estruturas condicionais e manipulação de informações.

Objetivo

O programa permite cadastrar cartas contendo informações sobre cidades e comparar seus atributos para determinar a carta vencedora.

Funcionalidades
Cadastro de cartas.
Armazenamento de informações de cidades.
Comparação de atributos entre cartas.
Exibição dos resultados da disputa.
Cálculo de indicadores conforme as regras do projeto.
Tecnologias Utilizadas
Linguagem C
Compilador GCC
Terminal/Console
Estrutura da Carta

Cada carta contém os seguintes atributos:

Estado
Código da carta
Nome da cidade
População
Área
PIB
Número de pontos turísticos
Como Executar
Compilar
gcc super_trunfo.c -o super_trunfo
Executar
./super_trunfo

No Windows:

super_trunfo.exe
